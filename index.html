Control de Stock — Ideas Étnicas

Compara Stock Inicial + Compras − Ventas contra el Stock Final reportado, artículo por artículo, para lo que se controla por unidad (bebidas embotelladas/enlatadas, vinos, etc). Todo se procesa en el navegador.

1. Local y período

El rango de fechas filtra Compras y Ventas (si esos archivos tienen columna de fecha mapeada). Stock inicial y final no se filtran: son una foto de un momento puntual.

2. Subí los 4 archivos de este local

Uno por cada concepto. Cada local puede tener columnas distintas — en el paso siguiente le indicás a la app dónde está cada dato.

2. Mapear columnas de cada archivo

Elegí qué columna corresponde a cada dato. Si Stock Inicial/Final tienen una columna de código de producto (ej. "N° de Control"), mapeala — es la forma más confiable de identificar el mismo artículo aunque le cambien el nombre entre períodos.

3a. Factores de conversión de Compras

Compras suele venir en packs/cajas y Stock cuenta unidades sueltas (botellas/latas). Indicá cuántas unidades de stock representa cada "Unidad de Medida" de Compras. Se sugiere automáticamente a partir del texto (ej. "PACK X 6" → 6); revisalo.

3b. Vincular artículos

La lista sale del Stock Inicial (son los artículos que ese local ya cuenta por unidad). Para cada uno, vinculá el/los nombres con que aparece en Compras y en Ventas — puede tener varios nombres distintos por errores de tipeo. Los ítems de barril/canilla se excluyen por defecto (no son "por unidad" según lo pedido). Esto queda guardado en este navegador.

4. Resultado

Stock Teórico = Stock Inicial + Compras − Ventas. Diferencia = Stock Final reportado − Stock Teórico.
